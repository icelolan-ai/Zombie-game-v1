# OUTBREAK VILLAGE — Zombie game v0.1

เกมต้นแบบ 3D Sandbox เล่นเป็นซอมบี้และแพร่เชื้อในหมู่บ้าน สำหรับเว็บบนมือถือและคอมพิวเตอร์

## เปิดเล่นผ่าน GitHub Pages

เมื่อเปิด Pages แล้ว ลิงก์จะเป็น https://icelolan-ai.github.io/Zombie-game-v1/

ใน repository ไปที่ **Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: main → /(root) → Save** แล้วรอ GitHub เผยแพร่

## วิธีเล่น

- มือถือ: จอยซ้ายเดิน ปุ่มกัดด้านขวา ปุ่มประตูเมื่ออยู่ใกล้ประตู ใช้ปุ่มหรือสองนิ้วซูม
- คอมพิวเตอร์: WASD/ลูกศรเดิน, Space กัด, E ประตู, Q หมุนกล้อง, ล้อเมาส์ซูม, Esc พัก
- กัดคนที่อยู่ใกล้และไม่มีผนังกั้น การกัดสำเร็จเริ่มเวลาติดเชื้อ 25 วินาที
- ซอมบี้ใหม่เดินไล่กัดต่อเอง ตำรวจและทหารยิงเมื่อมองเห็นฝ่ายซอมบี้
- เข้าอาคารเพื่อซ่อนหลังคาและลดความทึบผนัง ประตูที่ปิดยังขวางทาง NPC มนุษย์เปิดได้ ซอมบี้พังได้
- ร่างผู้เล่นตายจะเปลี่ยนไปคุมซอมบี้ที่ยังอยู่ ถ้ามีเพียงผู้ติดเชื้อให้รอการกลายร่าง
- เมนูพักปรับเลือด/คุณภาพภาพ บันทึก ส่งออก และนำเข้าเซฟได้
- พักเกมและสลับแอปหยุดเวลาเกม เซฟอัตโนมัติทุก 20 วินาทีที่เล่นอยู่ เก็บใน IndexedDB ของเบราว์เซอร์เครื่องนั้น

## ขอบเขตต้นแบบ

แผนที่ประมาณ 94 × 94 เมตร บ้าน 8 หลัง NPC 42 คน (ชาวบ้าน 35 ตำรวจ 5 ทหาร 2) และผู้เล่นหนึ่งตัว

มี A* หาเส้นทาง การตรวจแนวมองและกำแพง การกัด การแพร่เชื้อลูกโซ่ การยิง เลือดกระเซ็น/คราบพื้น กล้องติดตาม จอยสัมผัส และแผนที่ย่อ

โมเดลเป็นงาน procedural สไตล์เรียบง่าย แอนิเมชันขยับข้อต่อสร้างในโค้ด เสียงเป็นเสียงสังเคราะห์ ไม่มีบริการ AI หรือ CDN ระหว่างเล่น ตัวต้นแบบใช้ JavaScript ES modules และ Three.js r160 (MIT) ที่เก็บใน vendor เพื่อเปิดแบบ static ได้โดยไม่ต้อง build

ยังไม่ใช่เวอร์ชันหมู่บ้านเต็ม 400 เมตร ไม่มี multiplayer, ระบบภารกิจรายวัน, บุคลิกขั้นสูง, ศพแบบ ragdoll, เลือดบนเสื้อ และรอยเลือดติดตามผู้ติดเชื้อ เฟอร์นิเจอร์เป็นของตกแต่งและยังไม่กีดขวางทาง การเปลี่ยนฝ่ายเกิดทันทีที่กัดโดน+25 วินาที ท่ากัดเป็นท่า procedural สั้น ไม่มีระบบจับเหยื่อคู่เต็มรูปแบบ

เกมจำลอง NPC ทุกคนในฉากขนาดเล็กก่อน ยังไม่ได้ใช้ระบบจำลองพื้นที่ไกลแบบย่อ ความลื่นไหลและการใช้งาน Safari ต้องตรวจบน iPhone/iPad จริงก่อนยืนยันรุ่นอุปกรณ์ที่รองรับ

## พัฒนาและทดสอบ

ใช้ HTTP server เช่น `python3 -m http.server 8080` ที่โฟลเดอร์นี้ แล้วเปิด http://localhost:8080 (การเปิด index.html แบบ file:// ไม่รองรับ ES modules)

รัน `npm test` เพื่อตรวจเวลา 25 วินาที การเซฟ/โหลด การชน/แนวมอง เส้นทางเข้าบ้าน การแพร่เชื้อ AI และเปลี่ยนร่างผู้เล่น

- `src/simulation.js`: กฎเกมและเส้นทาง ไม่ขึ้นกับระบบภาพ
- `src/view.js`: ฉาก โมเดล กล้อง และเลือด
- `src/main.js`: ควบคุม UI เสียง เซฟ และนาฬิกาเกม
- `style.css`: หน้าจอมือถือและคอมพิวเตอร์
- `vendor/three.module.js`: Three.js r160 พร้อมใบอนุญาตใน `vendor/LICENSE-three.txt`

ค่าเวลาใน `INCUBATION` และข้อมูลอาคารใน `BUILDINGS` เป็นจุดปรับแต่งกลาง อย่าเปลี่ยนรูปแบบเซฟโดยไม่เพิ่ม version/migration
